# Source Code Core Modules (`src/`)

### 1. `mesh.py`
* Handles domain geometry generation, boundary marking, and spatial discretization triangulation.

### 2. `solver.py`
* Formulates the linear algebraic operators and resolves the quantum temporal dynamics.

### 3. `lieb_robinson.py`
* Contains post-processing, tracking, and validation tools for information speed limits aka Lieb-Robinson bounds.
